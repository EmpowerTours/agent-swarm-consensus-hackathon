# Live Demo - Agent Swarm Intent Auction

## How to Use

1. Click the **"🚀 Start Auction"** button
2. Watch 3 AI agents calculate competitive bids in real-time
3. See the winner announced with savings calculation
4. View the actual blockchain transaction link

## What You'll See

- **Live price feeds** from CoinGecko API
- **3 competing agents** with different strategies:
  - Conservative Agent (0.24% fee, 180s)
  - Contrarian Agent (0.36% fee, 60s)
  - Whale Agent (0.36% fee, 60s)
- **Winner selection** based on best output
- **Transaction link** to Monad Explorer
